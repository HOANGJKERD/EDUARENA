# 🎮 EduArena

**Học như chơi game**

EduArena là nền tảng học tập tương tác biến việc học thành cuộc phiêu lưu với phòng thí nghiệm ảo, đấu trường PvP và hệ thống rank.

## ✨ Tính năng

- 🧪 **Phòng thí nghiệm** - Vật lý, Hóa học, Sinh học tương tác
- ⚔️ **Đấu trường PvP** - Đấu với bạn bè, leo rank
- 🏆 **Hệ thống Rank** - Từ Đồng đến Huyền Thoại
- 📚 **Học tập** - Nhiều môn học đa dạng
- ⭐ **XP & Level** - Tiến trình hóa việc học
- 🔥 **Streak** - Duy trì thói quen học tập

## 🛠 Công nghệ

- **Next.js 14** - React framework
- **TypeScript** - Type-safe code
- **Tailwind CSS** - Styling
- **Prisma** - ORM
- **PostgreSQL** - Database
- **Auth.js** - Authentication
